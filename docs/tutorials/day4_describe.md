# Day 4: Describe a Strategy in a Sentence

**You will:** turn an idea into a strategy the platform can run, and
check it says what you meant.

1. In **Strategies**, choose **Describe a strategy**. Write what you want
   in your own words, for example: "Back Arsenal when the ratings like
   them more than the market does."
2. The assistant answers with the strategy as the engine will run it, in
   the same plain words for everyone: which markets, what it believes,
   when it bets and how much. If something is unclear it asks, with the
   choices as buttons. If something cannot be done it says so, rather than
   quietly doing something else.
3. Read it carefully. This rendering is what runs, not the conversation.
   Change anything by writing again; the page shows exactly what changed.
4. When it says what you mean, choose **Run this**. That freezes this
   version: later changes make a new version, and results are always
   kept with the version that produced them.

The assistant can also look things up for you (**Ask the research
assistant**). Every figure it quotes is checked against the data, and the
page says how many were.
